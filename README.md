# قالب تقويمي الاحترافي

قالب Flutter لتقويم عربي حديث يساعد على تنظيم الأحداث والمهام دون خادم.

## المزايا
- عرض شهري كامل مع تمييز اليوم الحالي واليوم المحدد.
- إضافة أحداث بتاريخ ووقت اختياري.
- أجندة للأحداث القادمة.
- تعليم الأحداث كمكتملة.
- حفظ محلي للأحداث.
- واجهة Material 3 مع وضع داكن.

## الإصدارات
Flutter 3.47.2، Java 17، Gradle 8.14، Android Gradle Plugin 8.11.1، Kotlin 2.2.20، compileSdk وtargetSdk 36.
